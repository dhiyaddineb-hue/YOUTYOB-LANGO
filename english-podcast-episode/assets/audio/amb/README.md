# amb/ — natural ambience beds

Real field recordings (pulled from open GitHub repos — licenses per source):
- ocean-deep.wav   ← Ambie "underwater.wav"  (MIT app assets, jenius-apps/ambie)
- fire-crackle.wav ← Ambie "fireplace.wav"   (MIT)
- rainforest.mp3   ← Ambie "Rainforest.mp3"  (MIT)
- eagle.mp3        ← Yellowstone Sound Library mirror rosuH/YSL (Bald Eagle; NPS recordings)
- bed-rain.wav (../bed-rain.wav) ← Ambie "rain.wav" (MIT)
Synthesized sleep-grade (24 dB turns): wind-arctic, wind-desert, ice-cracks, bed-night.
Each real bed is RMS-normalized to −23 dBFS to sit below the narrator.
