# Keyword color rules

English line only. Arabic stays cream so RTL stays clean.

| Class | Color | Words |
| --- | --- | --- |
| names | `#E11D48` | Maya, Omar, Sami, name |
| questions | `#7DD3FC` | what, what’s, where, how |
| verbs | `#5EEAD4` | do, like, meet, talking, take, read |
| places | `#FBBF24` | from, York, California, city |
| polite | `#C4B5FD` | nice |
| time | `#FDBA74` | free, time |

Never color more than three tokens in one caption window.
